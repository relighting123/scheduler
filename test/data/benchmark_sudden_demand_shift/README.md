# 수요 급변 벤치마크 데이터셋 (Sudden Demand Shift Benchmark)

이 시나리오는 공장의 초기 설비 배치 구성이 실제 계획 수요와 극단적으로 불일치할 때, 스케줄러가 필요한 공정으로 설비를 신속하게 전환(Conversion)하는 능력을 검증합니다.

## 구성 특징
- **수요 불일치**: `P1` 공정에는 다량의 설비(MODEL_A 6대)가 초기 배치되어 있으나 정작 계획 수량은 1,000개로 매우 작습니다. 반면 `P2`와 `P3` 공정은 각각 계획이 15,000개에 달해 대대적인 설비 투입이 필요합니다.
- **공정 전용성**: 각 제품은 하나의 설비 모델만 가용합니다 (`P1` - `MODEL_A`, `P2` - `MODEL_B`, `P3` - `MODEL_C`).
- **전환 필요성**: `MODEL_B`와 `MODEL_C`는 초기에 각각 `OP10` 공정에 전량(6대) 배치되어 있으므로, `OP20` 공정으로 즉시 장비를 전환해야 제품 완성이 가능해집니다.
- **목표 배치**: `P1`, `P2`, `P3` 각각의 `OP10`과 `OP20` 공정에 3대씩 균등 분배합니다.
