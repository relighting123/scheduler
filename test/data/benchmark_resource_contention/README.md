# 자원 경합 벤치마크 데이터셋 (Resource Contention Benchmark)

이 시나리오는 모든 제품이 특정 고효율 설비 모델(`MODEL_A`)을 필요로 하지만 전체 수량이 부족할 때, 스케줄러가 자원을 골고루 배분하여 평균 계획달성률을 최적화하는 능력을 검증합니다.

## 구성 특징
- **경합 요인**: `MODEL_A` 설비는 총 3대로 한정되어 있으며, `MODEL_B`와 `MODEL_C`는 UPH가 매우 낮아 `MODEL_A`를 효율적으로 분배해야만 높은 점수를 얻습니다.
- **초기 상태**: `MODEL_A` 3대가 `OP10` 공정에 분산 배치되어 있습니다.
- **목표 배치**: `P1`, `P2`, `P3` 각각의 `OP20` 공정에 `MODEL_A`를 1대씩 배치하여 세 제품 모두 균형 있는 생산 속도를 확보하도록 유도합니다.
